# 复习当前文件

打开一篇 Markdown 笔记，在命令面板运行 **Lexis：复习当前文件**。开始前可选模式、数量和遍数；默认临时突击、全部、1 遍。可自行绑定快捷键；桌面端和移动端使用同一命令。

- 只复习该笔记中的问答、双向问答、块级问答和挖空，沿用自定义卡片语法。
- 不要求加入词典，不创建复习计划，不包含双链目标文件。
- 按排期复习：新卡与到期卡，沿用每日新卡上限，跳过今天已完成的内容；正式评分更新原有排期。
- 临时突击：包括今天背过和未到期的内容，不受全局新卡/每轮上限阻断，可全部过两三遍；不会反复推长长期 FSRS 间隔。
- 两种模式都尊重搁置、归档和淘汰状态。数量按独立卡片/挖空计数，不复制卡片身份。
- 一批结束后可再背本批，或配置剩余部分。开始前也可将同一范围与模式保存为计划。
- 没有可复习卡片时显示现有的本轮结束页面，不自动创建卡片或重置历史。

计划可直接使用词典、单文件、文件夹、标签或目录文件内双链；详见 [复习模式与计划](review-modes.md)。
