# 复习模式与计划

临时复习、当前文件命令和计划编辑器复用同一套范围、内容、模式、数量与遍数控件。文件夹、文件和标签均可输入并从模糊候选中选择。排序收在折叠区内。

## 两种模式

| 模式 | 范围内哪些卡片参与 | 数量和排期 |
| --- | --- | --- |
| 按排期复习 | 新卡与到期卡，跳过今天已完成的卡片 | 沿用每日新卡限制，评分更新原有 FSRS 状态 |
| 临时突击 | 也包含未到期、今天已完成的卡片 | 全部或指定数量，可重复多遍；练习不改 FSRS、笔记属性或正式复习历史 |

两种模式都排除搁置、归档与淘汰内容。多挖空按每个独立挖空计数；逐个/全部显示答案仍在卡片上选择。

“复习当前文件”默认突击全部、1 遍。开始前确认，不会在打开窗口时写入设置。数量留空表示全部；重复同一批时保留原卡片身份。结束后可以再背一遍，或选择剩余批次及其数量。

## 计划

计划保存名称、范围、内容、模式、每日目标数量、遍数（仅突击）、可选截止日期与排序。范围可选词典、文件夹、标签、单文件或目录文件内双链；文件不必先加入词典。

- 留空截止日期即为长期计划，每天重新生成任务。
- 日期只用于展示剩余天数/逾期状态，并让近期截止的计划排在前面；不是改写卡片排期或自动保证按时完成的依据。
- 排期计划的每日数量留空时沿用全局每日目标。突击计划留空则每天全部；例如 30 张、2 遍表示当天完成 60 次卡片练习。
- 忘记的卡片在当前遍重试；成功后计一次，跳过不计完成。搁置的卡片不会在下一遍重新出现。
- 修改计划名称或日期不重置进度。增加遍数、改变数量或范围也保留已练习卡片的计数，以卡片身份匹配。
- 练习撤销和保存失败会回退计数；已保存的计划练习进度可在重启后继续。临时练习的轮次仅属于当前会话，不伪装成长期复习历史。

## 数据与同步

计划、每日任务与突击进度统一保存在指定数据文件夹的 `reviews` 子目录，分别对应 `reviewPlans`、`reviewDailyTargets` 和 `reviewPracticeProgress`（计划 ID → 日期与每张卡的成功遍数）。不再写入隐藏的插件配置文件。

计划编辑器底部显示当前可见的数据目录。整篇笔记的 FSRS 属性仍在笔记中；语法卡状态与近期历史跟随数据目录。

跨设备同步配置和整个数据文件夹，并统一更新各设备。旧数据一次性转换，之后不再导入旧版写回的学习字段。详细历史默认保留 90 天，不影响当前排程；具体迁移、冲突边界和清理规则见 [learning-storage.md](learning-storage.md)。
