# Lexis Desktop — macOS preview

选中文字，松开鼠标后显示 Lexis 药丸。点查词看解释，点 `+` 打开添加区；也可以按 **⌃⌥L**。这是选区读取，不是屏幕 OCR，也不会给所有软件自动高亮。

## 安装与连接

1. 解压本机构建的 ZIP，将 `Lexis Desktop.app` 放到固定位置，例如“应用程序”，再打开。
2. 打开 Obsidian 的 Lexis 桥接，在桌面端齿轮设置中填同一端口与令牌。默认端口 `12345`。保存后点击底部刷新按钮测试连接。
3. 在“系统设置 → 隐私与安全性 → 辅助功能”允许 Lexis Desktop。未授权时不自动读选区，仍可手动输入查词。
4. 拖选或双击选词后，点击鼠标旁的查词或 `+`。药丸本身不抢焦点、不发请求；点击后才打开窗口。窗口关闭后仍驻留菜单栏。
5. 菜单栏“自动划词药丸”可随时开关。设置中的“划词后显示药丸”也控制同一开关。快捷键被占用时，可在设置中更换组合。

主窗口和设置窗口不置顶；只有临时划词药丸保持在选区旁。底部显示划词状态，可区分“未授权”“已检测划词”“未读到选区”，不展示或记录原文日志。

Obsidian 必须运行且桥接已开启，才能查词或保存。自动划词默认开启，**默认不排除任何外部 App**；不会自动探测浏览器是否装了插件。想避免两套药丸时，在设置的“不显示药丸的 App”里点 `+` 自行选择，取消排除不会删除 App。排除只影响自动药丸，不影响主动快捷键。Lexis 自己的窗口不触发药丸。

只有提供可读取文本选区的软件才能自动显示；图片、扫描 PDF 或某些自绘文字不保证支持，读不到时不会显示空药丸。可改用快捷键、手动输入或复制后点粘贴。没有偷偷模拟 Cmd+C 的兜底。

此包为本机临时签名，没有 Apple 公证，不保证在其他 Mac 上直接打开。若系统阻止，请按系统提供的“仍要打开”流程处理，不要关闭系统安全检查。移动应用或重新签名后，辅助功能权限可能需要重新授权。首轮真实点击与授权测试尚待用户确认。

ChatGPT 等网页文字层额外尝试 `AXSelectedTextMarkerRange`，不再强制要求选区位置框。遇到明确支持 `AXManualAccessibility` 的应用，会在首次读取失败时请求启用其文字辅助支持并等待一次重试；不会对所有 App 设置 `AXEnhancedUserInterface`，也不会模拟复制。不保证每种应用版本都能读取。

## 功能边界

- 查词：标题与别名匹配，完整词优先，再匹配前缀和子串。最多展示 20 个候选，不在输入时发网络请求。
- 详情：Obsidian 返回最终 HTML 与公式样式；桌面不另装 MathJax。支持 Markdown、列表、内链、本地附件图片。窗口可缩放并记住大小与位置。
- 添加：点击底部 `+`，选择保存新词的文件夹，可附出处原文。记住每个库上一次选择。标签等没有直接写入位置的词典不单独当保存目的地。已有词条沿用桥接的追加规则；内联词条在 Obsidian 编辑，避免误写整篇词典。
- 跳转：右上角箭头打开原笔记。正文中的 Obsidian 内链也交给 Obsidian，网页链接交给默认浏览器。
- 远程图片和自动出处搜索暂不加载。不会把其他软件的窗口标题猜成网址，也不会自动采集上下文。
- 暂无 OCR、全屏扫描、全局自动高亮、独立复习、开机自启或自动更新。

## 数据与隐私

- 词条仍是原来的 Obsidian Markdown，添加通过现有桥接写入；不直接读取或修改 Vault 文件。
- 只连接 `127.0.0.1`，令牌放请求头，不放 URL，不写日志。HTTP 重定向不携带令牌继续访问。
- 令牌由系统钥匙串保存；端口、快捷键、自动划词开关、手选 App 排除项、上次词典、窗口尺寸存于 `com.heptazero.lexis-desktop` 的本机偏好。不跨设备同步。
- 词库索引和当前详情只保留在运行内存，不保存磁盘离线缓存。按刷新重新读取词库；外部改词库后可刷新。
- 开启自动划词后，只在拖选或双击选词结束后读取选区；快捷键也可主动读取。只观察鼠标手势和用于收起药丸的键盘事件，不读取或记录键入字符，不记录选区日志、不截图、不自动复制或监听剪贴板。“粘贴”按钮才读取一次剪贴板。
- 普通单击、滚动、打字或切换软件会收起药丸；关闭自动划词时移除事件监听。读取在后台进行，最多一个自动选区读取在途，新操作会使旧结果失效；不读密码框，不截断超长选区来误建词条。
- 详情禁用脚本、表单、外部图片与字体自动请求；数据 URI 附件与公式字体可展示。

## 构建与检查

macOS 13+，本机 Swift 工具链，未使用第三方 Swift 包。无需启动 Xcode 界面。

```sh
cd pkg/desktop-macos
swift run -j 2 LexisChecks
sh scripts/build.sh
```

本地开发不需要反复下载 ZIP。退出旧版后运行：

```sh
sh scripts/install-local.sh
```

它重新构建并覆盖 `/Applications/Lexis Desktop.app`，不删除设置、钥匙串或词库，不强退或自动启动应用。临时签名更新后可能仍需重新授权；这不是 App 内自动更新。也可手动将 `dist/Lexis Desktop.app` 拖入应用程序替换旧版。

产物在 `dist/Lexis Desktop.app` 和 `dist/lexis-desktop-macos-<架构>-0.1.2.zip`。默认构建本机架构，不是通用二进制。脚本限制两个编译任务，不会自行安装开发工具或修改系统权限。

桌面端独立版本采用 `desktop-v*` 标签，并标记 GitHub 预发布，不标记为 Latest；只附桌面安装包，不附 Obsidian 的 main.js、manifest.json、styles.css，不改变其他客户端的稳定版。

实现按本机入口、选区读取、快捷键、桥接、界面和存储分开。协议模型、检索、链接和安全文档策略有无界面自动测试；这些不代表已验证所有软件的选区支持。测试用独立检查程序，不需要另装 Xcode 的 XCTest。

Apple APIs: [选区属性](https://developer.apple.com/documentation/applicationservices/kaxselectedtextattribute), [WKWebView](https://developer.apple.com/documentation/webkit/wkwebview).
